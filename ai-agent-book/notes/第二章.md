# 1. 什么是Token的中间计算？
比如 `mulehang喜欢打瓦`，经过tokenizer后，大致可以想象成：

mulehang,喜欢,打,瓦

每个token对应一个token ID，如：
```txt
mulehang -> 1224
喜欢 -> 1434
打 -> 2155
瓦 -> 3565
```

但神经网络不能直接拿token ID做语言理解，需要先向量化

```txt
"mulehang"
   ↓ Embedding
[0.17, -0.83, 0.42, ..., 0.19]
```
实际可能上千维

然后进入第一层Transformer：
```
mulehang的 embedding
       ↓
Transformer Layer 1
       ↓
mulehang的第 1 层 hidden state
       ↓
Transformer Layer 2
       ↓
mulehang的第 2 层 hidden state
       ↓
...
       ↓
Transformer Layer N
```
这些隐藏状态(hidden state)，都可以宽泛地叫做token的中间计算结果
