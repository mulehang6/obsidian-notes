# 1. mybatis和mybatis-plus有什么区别？你之前学过mybatis，为什么项目里面又换成mybatis-plus了呢？

MP是在MB基础上的增强工具，不是替代品，主要区别就在于MP在MB的基础上封装了一层，提供了很多现成的CRUD操作。

如果是在Service层，需要继承`IService<?>`，或者让实现类继承`ServiceImpl<?Mapper, ?>`，就可以使用save、getById、updateById、removeById、list、page、saveOrUpdate等方法

条件查询一般会搭配LambdaQueryWrapper，比如eq、like、gt、orderByDesc，条件更新可以用LambdaUpdateWrapper搭配set

因为简单的sql就可以直接用java代码来实现了，可以提升开发效率
# 2. 在使用mybatis的时候，有个 `$` 和 `#` 这两个分别是做什么的？

例：
```java
@Select (select * from table where column1 = #{column1})
```

`#{}` 是 MyBatis 的预编译占位符，底层会被替换成 `?`，然后通过 `PreparedStatement` 设置参数，能够自动处理类型和字符串引号，也能防止 SQL 注入，所以普通参数都应该用 `#{}`。

`${}` 是字符串替换，会把参数原样拼接到 SQL 里，不走预编译，有 SQL 注入风险。例如参数是`1 or 1 = 1`，完整语句就是`select * from table where id = 1 or 1 = 1`，条件永远为真

# 3. 技术派还是派聪明来着，令牌校验这块怎么做的？

跟这个一起看 [[面试回顾 2026.6.2 武汉合力亿捷#11. 用户登录的令牌怎么生成的？]]

1. 服务端先校验token的签名、issuer和过期时间
2. jwt验证通过后，再根据token去redis里面查，并且对比重要字段，例如userId是否一致。
   这样做的原因是，如果不加redis，这个jwt一旦签发，在过期前天然无法主动失效，加了redis之后，用户登出，管理员踢人，账号封禁的时候，只要把redis里面的token删掉，这个jwt就立刻失效了
3. 最后是检查用户是否被封禁，如果已经被封禁，系统会主动清理这条session，组织访问

# 5. Spring的常用注解

报菜名来了

## 1. 组件注册类

`Component`：通用组件标记，把一个类交给Spring管理
`Controller`：用于控制器层，通常处理页面请求
`Service`：本质上与`Component`类似，只是语义更明确，表示业务逻辑类
`Repository`：用于DAO，Mapper，持久层，在Mybatis项目中，一般使用`@Mapper`或`@MapperScan`

## 2. 依赖注入类

`Autowired`：
`Resource`：按名称优先注入，找不到再按类型
`Qualifier`：当一个接口有多个实现类时，用这个指定注入哪个Bean

## 3. 配置类

`@Configuration`：声明当前类是配置类
`@Bean`：把方法返回值注册到Spring容器中
`@Value`：读取配置文件里的值
`@ConfigurationProperties`：批量绑定配置，项目中更推荐这种

## 4. Web开发常用

`@RestController`：表示这个Controller返回的不是页面，而是JSON数据
`@RequestMapping`：映射请求路径，可以用在类上，也可以用在方法上
`@GetMapping`、`@PostMapping`、`@PutMapping`、`@DeleteMapping`：对应HTTP请求方法
`@RequestParam`：接受URL参数，如：`GET /users?page=1&size=10`
`@PathVariable`：接受路径请求，如：`GET /users/1`
`@RequestBody`：接受JSON请求体
`@ResponseBody`：表示方法返回值直接作为响应体返回，用了`@RestController`之后，一般不需要再写这个

## 5. 事务相关注解

`@Transactional`：声明事务，中间发生异常会回滚

## 6. AOP相关

`@Aspect`：声明切面类
`@Around`：环绕通知，方法执行前后都可以处理

## 7. Spring Boot 常用

`@SpringBootApplication`：启动类注解
`@EnableAutoConfiguration`：开启自动配置，SpringBoot会根据classpath里的依赖自动配置Bean，通常不用单独写，`@SpringBootApplication`已经包含了
`@ComponetScan`：指定扫描哪些包下的组件

## 8. Mybatis / Mybatis-Plus常用

`@Mapper`：标记Mapper接口
`@MapperScan`：批量扫描Mapper接口
`@TableName`：MP中指定实体类对应的表明
`@TableId`：指定主键字段
`@TableField`：指定字段映射，或者声明某个字段不是数据库字段
`@TableLogic`：逻辑删除

## 9. 参数校验相关

`@NotNull`：不能为null
`@NotBlank`：字符串不能为空白
`@NotEmpty`：集合或者字符串不能为空
`@Email`：邮箱格式
`@Min`：最小值
`@Max`：最大值
`@Size`：长度或集合限制大小
`Pattern`：正则校验

## 10. 异常处理相关

`@ControllerAdvice`：全局异常处理类
`@ExceptionHandler`：指定处理哪种异常
`@RestControllerAdvice`：等价于`@ControllerAdvice` + `@ResponseBody`

# 7. (很常见)你的项目为什么要用ES？直接用MySQL查询不行吗？

因为有全文检索的需求。MySQL适合做事务型查询，比如根据id、分类等，但是如果要对文章的标题、摘要、正文做关键词搜索，用`%like%`性能不好，普通索引可能也会失效，而且中文分词，相关性排序、高亮这些能力也比较弱

ES底层是倒排索引，适合全文搜索，所以项目里让MySQL作为主库保存原始数据，ES作为搜索索引库提高查询效率，数据同步可以通过canal实现

# 11. 用户登录的令牌怎么生成的？

把userId和一个随机的会话标识放进payload，同时写issuer和过期时间，然后用服务端secret做HMAC256签名。

不过它不是无状态JWT，因为生成后还会把token映射关系放进redis，后续校验会做JWT + redis双重校验
