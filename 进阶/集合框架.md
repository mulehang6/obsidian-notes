# 1. HashMap

## 1. hash方法的原理

源码：
```java
// jdk 8
static final int hash(Object key) {
    int h;
    return (key == null) ? 0 : (h = key.hashCode()) ^ (h >>> 16);
}
```

哪里用到了呢？看一下put方法的源码

```java
// jdk 8
public V put(K key, V value) {
    return putVal(hash(key), key, value, false, true);
}
```

### hash方法的作用

HashMap底层是通过数组的形式来实现的，初始大小是16，也就是说，最开始的时候，需要通过键的哈希码在16个大小的数组中选一个确定一个位置(索引)，怎么确定呢？

先记住这个结论：==通过(n - 1) && hash==，其中n为数组的长度，变量hash就是通过hash方法计算之后的结果。

理论上，哈希码(哈希值)是一个int类型，范围在-2147483648 到 2147483648之间，大约40亿，内存肯定是放不下的。HashMap扩容之前的数组长度又只有16，所以这样算的哈希值肯定是不能直接拿来用的，用之前要和数组的长度做与运算`(n - 1) && hash`，有些地方叫取模运算，有些也叫取余运算，得到下标才可以。

### 取模运算、取余运算、与运算

取模和取余严格来讲，是两种不同的运算。
在Java中，取余一般用%，取余则是`Math.floorMod`。区别如下：
- 如果操作数都是正数，那么结果是一样的。
- 如果是负数，那么取模的商会向负无穷靠近；取余则是0

例子：
```java
int a = -7;
int b = 3;

// a 对 b 取余
int remainder = a % b;
// a 对 b 取模
int modulus = Math.floorMod(a, b);

System.out.println("数字: a = " + a + ", b = " + b);
System.out.println("取余 (%): " + remainder);
System.out.println("取模 (Math.floorMod): " + modulus);

// 改变 a 和 b 的正负情况
a = 7;
b = -3;

remainder = a % b;
modulus = Math.floorMod(a, b);

System.out.println("\n数字: a = " + a + ", b = " + b);
System.out.println("取余 (%): " + remainder);
System.out.println("取模 (Math.floorMod): " + modulus);
```

输出：
```txt
数字: a = -7, b = 3
取余 (%): -1
取模 (Math.floorMod): 2

数字: a = 7, b = -3
取余 (%): 1
取模 (Math.floorMod): -2
```

何意味？

#### 1. 取余

余数的定义是基于常规除法的，所以他的符号总是与被除数相同，商趋向于0。

例如，对于 `-7 % 3`，余数是`-1`。因为`-7 % 3`可以有两种结果，一种是商`-2`，余`-1`，还有一种是商`-3`，余`2`。因为取余的商趋向于0，那么很显然这里的结果就应该是`-2`了

#### 2. 取模

取模也是基于除法的，只不过他的符号总是与除数相同，商趋向于负无穷。

例如，对于`Math.floolMod(7, -3)`，也有两种结果，同上，这里很显然就选商`-3`的情况。

#### 3. 与运算

当数组的长度是2^n时，有`hash & (length - 1) = hash % length`。为什么呢？

当数组长度是2^n时，`hash % length`相当于`hash >> n`，也就是把n右移了n位，此时就得到了`hash / 2^n`的商。被移动的部分，则是`hash % 2^n`，也就是余数。

`hash % length`的操作是求hash除2^n的余数。在二进制中，这个操作的结果就是hash的二进制中最低n位的值，例如26的二进制是11010，要算26 % 8，那么结果自然就是商3余2，正好与最低3位010相同。

当执行`hash & (length - 1)`时，本质上就是保留hash二进制表示的最低n位，其他高位都清零。
例如hash = 14，length = 2^3 
```txt
 1110
 0111
&---------
 0110
```

结果为6

HashMap取模运算有两处
```java
final V putVal(int hash, K key, V value, boolean onlyIfAbsent, boolean evict) {
    // 数组
    HashMap.Node<K,V>[] tab;
    // 元素
    HashMap.Node<K,V> p;

    // n 为数组的长度 i 为下标
    int n, i;
    // 数组为空的时候
    if ((tab = table) == null || (n = tab.length) == 0)
        // 第一次扩容后的数组长度
        n = (tab = resize()).length;
    // 计算节点的插入位置，如果该位置为空，则新建一个节点插入
    if ((p = tab[i = (n - 1) & hash]) == null)
        tab[i] = newNode(hash, key, value, null);
}
```

```java
final Node<K,V> getNode(int hash, Object key) {
    // 获取当前的数组和长度，以及当前节点链表的第一个节点（根据索引直接从数组中找）
    Node<K,V>[] tab;
    Node<K,V> first, e;
    int n;
    K k;
    if ((tab = table) != null && (n = tab.length) > 0 &&
            (first = tab[(n - 1) & hash]) != null) {
        // 如果第一个节点就是要查找的节点，则直接返回
        if (first.hash == hash && ((k = first.key) == key || (key != null && key.equals(k))))
            return first;
        // 如果第一个节点不是要查找的节点，则遍历节点链表查找
        if ((e = first.next) != null) {
            do {
                if (e.hash == hash && ((k = e.key) == key || (key != null && key.equals(k))))
                    return e;
            } while ((e = e.next) != null);
        }
    }
    // 如果节点链表中没有找到对应的节点，则返回 null
    return null;
}
```
